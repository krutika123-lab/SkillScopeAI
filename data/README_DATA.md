# Dataset information

`job_postings.csv` has 700 synthetic sample records and 18 columns:
job_id, company, job_title, location, experience_level, experience_required,
employment_type, salary_min_lpa, salary_max_lpa, currency, posted_date,
skills, description, education, remote_option, industry, company_size, source.

`role_skill_reference.csv` is a small role-to-skill reference table.

These are generated sample records for application development, not actual vacancies or verified market research. Replace with permitted real data for genuine market conclusions.
